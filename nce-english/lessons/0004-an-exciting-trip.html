激动人心的旅行

这一课的唯一收获：事情发生在过去，但现在还留着结果，就用 have / has + 过去分词。 不是「过去做过什么」，而是「现在因此是什么状态」。

01这一课学什么

本课句型：主语 + have / has + 过去分词。

前三课分别管「过去」（第 1 课）、「现在和此刻」（第 2 课）、「给谁什么」（第 3 课）。 这一课管的是「已经做完，所以现在是这样」。 读 release notes 和升级说明时，最常撞见的就是 has been added、has been removed、 has been deprecated——它不是在讲过去某个时刻，而是在告诉你「现在这个东西有了 / 没了 / 该换了」。

先看一句真的。下面是 Spring Boot 3.0 发布说明里的一句：

Spring Boot 3.0 has migrated from Java EE to Jakarta EE APIs for all dependencies.

Spring Boot 3.0 已把所有依赖从 Java EE 迁移到了 Jakarta EE API。

has migrated 的重心不在「哪一年迁的」，而在「现在用的已经是 Jakarta EE」。 换成 Spring Boot 3.0 migrated ... last year，就变成讲一件过去的事，读者得自己去推「那现在呢」。 这一课要练的就是：把「现在的结果」直接说出来。

来源：Spring Boot 3.0 Release Notes · Third-party Library Upgrades · Jakarta EE 迁移句

为什么是这一课：课文整段都在讲「蒂姆现在是什么状态」，而不是「他去年做了什么」。

I have just received a letter from my brother, Tim.
我刚刚收到弟弟蒂姆的来信。
He has been there for six months.
他在那儿已经待了六个月。

02生词和搭配

单词不单独记，记「和谁一起出现」。这一课只给四组。

1. have / has + 过去分词：现在完成时的骨架

中文意图：事情已经发生，我要说的是它现在的结果。

have（I / you / we / they）｜has（he / she / it）+ 过去分词

怎么用：主语是第三人称单数就用 has，其余用 have； 后面跟的是过去分词，不是过去式。规则动词两者长得一样（receive → received）， 不规则动词不一样（go → went → gone，be → was / were → been）。

He have received a letter. → He has received a letter.

中文没有「过去式 / 过去分词」这层区分，所以最容易把 I have went 这种句子写出来。 记住：have 后面跟的是 gone，不是 went。

2. just / already / never 放哪儿

中文意图：刚做完、已经做完、从来没做过——都在说「现在」的结果。

have / has + just / already / never + 过去分词

怎么用：这三个词站在 have 和过去分词之间。 just = 刚刚；already = 已经（比预期早）；never = 从来没有。 课文里三个词都出现过：have just received、has already visited、has never been （just 还出现在 has just bought 里）。

I have already finished it.｜I have finished it already.

中文「我已经做完了」的字序容易让人把「已经」放句首；英文的两个自然位置是： 夹在 have 和过去分词之间（更常见），或放句尾（更口语）。 never 和 just 通常只放中间。

3. for 跟一段时间，since 跟起点

中文意图：说这件事已经持续了多久。

for + 一段时间（for six months）｜since + 起点（since 2020）

怎么用：for 后面是长度：for two years、for ten minutes； since 后面是时间点：since Monday、since last year。 两者都能和现在完成时连用，但句子重心仍是「现在」。

He has been there since six months. → He has been there for six months.

six months 是一段时间，不是起点。要说起点，就得 since January。

4. have been to / have gone to / have been in

中文意图：分清「去过（人回来了）」「去了（人还在那儿）」「待在那儿多久」。

have been to 去过 ｜ have gone to 去了 ｜ have been in 待在某地

怎么用：课文说 He has been there for six months——人一直在那儿； has gone to Alice Springs——去了那个地方，现在人在那儿或正往那儿去。 说「旅行经历」用 have been to：I have been to Australia twice。

He has been to Australia for six months. → He has been in Australia for six months.

have been to 说的是「去过（经历）」，不能跟 for + 时段 讲「待了多久」； 要说得久，用 have been in。注意 has gone to ... for six months 也可能出现， 但那是「去了、准备待六个月」，不是「已经待了六个月」。

不要背单词表。下面这 6 个词只要求「看见能认出来」， 拼写交给教材。完整词表在全文批注版。

03一句一句拆开看

四句核心句，还是那三步：找动词 → 定时间 → 切主干。 这一课第三步多问一句：这个动作是「过去发生过」，还是「现在还在影响现在」？

I have just received a letter from my brother, Tim.

我刚刚收到弟弟蒂姆的来信。

我是这么想的：找动词——不是 receive 一个词，而是 have received 两个词合起来的动词组； just 夹在中间，不参与变化。received 是规则过去分词（receive + d）。 定时间——just 锁死「刚刚」，说的是「信现在在我手上」。 切主干：I + have just received + a letter；from my brother, Tim 是修饰 a letter 的。 和 I received a letter 比：过去式只讲「收到了」这个动作，现在完成时讲「我现在有这封信」。

He has been there for six months.

他在那儿已经待了六个月。

我是这么想的：找动词——has been，be 的现在完成时；been 不是 was。 定时间——for six months 说明这个状态从六个月前持续到现在。 切主干：He + has been + there，for six months 是时间长度。 关键区别：He went there six months ago. 只说他六个月前去了； He has been there for six months. 说他现在人还在那儿，已经待了六个月。

He is working for a big firm and he has already visited a great number of different places in Australia.

他在一家大公司工作，已经去过澳大利亚很多不同的地方了。

我是这么想的：这句有两个分句，各有一个动词组。 前半 is working 是现在进行时——第 2 课的骨架，说他现阶段的工作状态； 后半 has already visited 是现在完成时，already 夹在 has 和过去分词之间。 切主干：He + is working + for a big firm；he + has already visited + a great number of different places。 in Australia 修饰 places。注意前半用进行时、后半用完成时，两种「现在」并不冲突： 一个说「眼下在做」，一个说「截至现在已完成」。

My brother has never been abroad before, so he is finding this trip very exciting.

我弟弟以前从未出过国，所以觉得这次旅行非常激动人心。

我是这么想的：前半 has never been：never 夹在 has 和 been 之间， 说「从过去到现在一次都没有」；before 放句尾，配合 never 用。 后半 is finding 是现在进行时——第 2 课的骨架，说他此刻的感受。 切主干：My brother + has never been + abroad；he + is finding + this trip + very exciting。 so 连接因果：因为「从来没出过国」，所以「现在觉得特别新鲜」。 注意 abroad 是副词，前面不加 to。

其余课文句子（Tim is an engineer、买澳大利亚车、He will soon visit Darwin、 he will fly to Perth）见全文批注版。 will 将来时不在本课要求内，认得即可。

04平时聊天怎么说

三个场景都来自普通工作日，和前面三课那九个不重复。

同事闲聊休假回来，被问新开的店

— Have you been to the new coffee place yet?
— Not yet. I have just got back from a trip.

— 你去过新开的那家咖啡店了吗？
— 还没。我刚出差回来。

问「到目前为止去过没有」用 Have you been to ... yet； yet 放句尾，用于疑问和否定。have just got back 说「刚回来，人现在在这儿」。

别这么说：「Have you went to the new coffee place?」——have 后面跟过去分词 been，不是过去式 went。

电话确认构建是否跑完

— Has the build finished?
— Yes, it has. It has already passed all the tests.

— 构建跑完了吗？
— 跑完了，测试也全都过了。

简短回答只重复助动词：Yes, it has.，不用再说一遍 finished。 already 放在 has 和过去分词之间，表示比预期早完成。

别这么说：「It has finished yesterday.」——yesterday 是具体的过去时间，只能配过去式：It finished yesterday.

日常安排刚搬家，聊周边

— I have just moved to a flat near the office.
— Nice. Have you found a good coffee place yet?

— 我刚搬到公司附近的一间公寓。
— 不错。你找到合适的咖啡店了吗？

「刚搬来、现在住这儿」用 have just moved； 问「到目前为止找到没有」用 Have you found ... yet，答「还没」用 Not yet。

别这么说：「I have moved to a flat last week.」——last week 锁死过去，改成 I moved to a flat last week.

这三个场景的英文句已经登记在 已学骨架总表 第 02 节，明天开新课前先盖住英文说一遍。

05技术文档里怎么写

下面三句是 Spring Boot 3.0 发布说明里同一小节的连续原文，逐字摘录、没有改写。 加粗的是本课句型相关的部分。has been added 这类句子，是 release notes 里最标准的一句「现在有这个东西了」。

A new configuration property, spring.kafka.listener.async-acks, for enabling async acks with Kafka has been added. To enable async acks, set the property to true. The property only applies when spring.kafka.listener.async-mode is set to manual or manual-immediate.

为了在 Kafka 里启用异步确认，新增了一个配置项 spring.kafka.listener.async-acks。 要启用异步确认，把这个配置项设为 true。 这个配置项只在 spring.kafka.listener.async-mode 设为 manual 或 manual-immediate 时才生效。

第 1 句：主干是 A new configuration property ... has been added——中间插了一长串修饰， 先别管，直接读「一个新配置项已经被加了进来」。has been added 是本课骨架的被动版： has + been + 过去分词，说的是「现在这个属性存在了」。
第 2 句：To enable ..., set ... 是操作步骤，先用 To + 动词原形说目的， 再用动词原形下指令。 这一句不是本课的骨架，照着做就行；它和上一句的时态没有冲突——上一句讲「现在有什么」，这一句讲「你该怎么做」。
第 3 句：only applies 是一般现在时三单（第 2 课），is set 是一般现在时被动（只要求认得）， 都在说这个配置项的常态规则。整段读下来，时态在三种「现在」之间切换，但都不是过去的故事。

来源：Spring Boot 3.0 Release Notes · Enabling Async Acks with Apache Kafka（同一小节连续三句）

读 release notes 时先问自己：这句是在讲「过去某一次」，还是在讲「现在的结果」？ 看到 has / have + 过去分词，直接翻成「已经……」；看到 was / were + 过去分词，才是「当时被……」。

06开会和演示怎么说

这六句是我们自己写的练习句（口语脚本本来就是造出来的，不是文档原文）， 每一句只用已学过的骨架：本课的现在完成时、第 1 课的过去式、第 2 课的一般现在时与现在进行时、 第 3 课的双宾语。左边是你想表达的中文，右边是英文。

  1. 演示介绍新增了一个配置项

    We have added a new setting for the export timeout.

    用第 03 节第 1 句：have added 说「现在这个配置项有了」。 演示里讲新功能，先给结果，不用交代是哪天写的代码。

  2. 演示解释旧开关被替换

    We have replaced the old flag with a new setting, and the old name has already disappeared from the docs.

    用第 03 节第 1、3 句：两个分句都用现在完成时，already 夹在 has 和 disappeared 之间。 replace A with B = 用 B 替换 A。

  3. 演示有人问测过没有

    — Have you tested it on Java 17?
    — Yes, we have already run it on Java 17.

    用第 03 节第 1 句的疑问形式：Have + 主语 + 过去分词。 回答仍用现在完成时，因为重点是「现在已验证」；run 的过去分词还是 run。

  4. 会议没听清一个数字，请对方再说一遍

    Sorry, I have not caught that — could you give me the number again?

    前半用第 03 节第 1 句的否定形式：have not + 过去分词； 后半用第 3 课的双宾语 give me + 物。比 say that again 具体。

  5. 会议复述一遍，确认自己听懂了

    So the migration has already started — do I have that right?

    前半用第 03 节第 1、3 句：has already started 说「现在已经在跑了」； 结尾 do I have that right 是第 2 课的 Do 疑问，用来把「没听懂」变成「在对齐」。

  6. 会议不太同意，但不想直接说 no

    I am not sure that has worked — the last change gave us more problems than it solved.

    前半用第 03 节第 1 句说「到现在为止没见效」； 后半用第 3 课的过去式双宾语 gave us 把不同意挂在上一次的结果上。

练法：盖住右边的英文，只看中文意图，每句说三遍。 说不出来的那句，回第 03 节重看它标的那个骨架。

07拿去和 AI 练

练习在 AI 对话里。三个角色各一段提示词，点按钮复制，粘进对应工具即可。

陪练 · 建议用豆包（有语音通话，能真的开口说）。 让 AI 扮演同事跟你英文对话，逼你在「过去式」和「现在完成时」之间切换。

批改 · 建议用 Trae 或 codex（能读本仓库文件）。 把你写的句子丢给它，重点看过去分词和时间词。

出题 · 建议用 Trae 或 codex。 替代纸质默写：三句中文，你写英文，再对答案。

更多通用提示词见AI 提示词库。 三个角色的输出契约都一样：先总评、只改一处、再给升级版。
