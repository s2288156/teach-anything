# Mission: 用《新概念英语》第二册读懂英文技术资料

## Why

目标是能独立读懂英文技术资料——官方文档、报错信息、GitHub issue、技术博客与论文，不必每句都先翻译。
现在的问题不是单词量，而是句子的骨架：长句读到哪里断、哪个是主干、哪个是修饰，基本靠猜。

## Success looks like

- 能拆开技术文档里的长句，指出主干和修饰成分，而不是整句猜意思。
- 认得出第二册覆盖的时态与语态（一般过去时、过去进行时、现在完成时、被动语态等），并说清它们表达的时间关系。
- 遇到生词能判断词性，能靠搭配和上下文猜出大概意思。
- 能仿写课文句式，写出语法正确的句子。
- 能在真实场景里用出来：周末聊安排、电话里解释没接、给同事写一条状态更新。

## Constraints

- 起点：初中基础，偏薄。词性与句子成分需要重新讲，不默认已知。
- 节奏：每天一课。**不卡时长**，以走完「示范 → 你练 → 检索 → 产出」四步闭环为完成标准；
  走完就结束，不凑时长，也不砍环节。结构细节见 `NOTES.md`。
- 讲解以中文为主，英文术语首次出现时给中文对照。
- 每课必须落到现实用法：3 个上班族对话场景，各配一条「别这么说」误用对照；
  再往技术资料里迁移。不做摸底测验，也不建新的学习记录档。
- 桥接语料取自 Spring Boot / Spring Framework / OpenJDK 生态的官方文档
  （报错栈、issue、release notes、troubleshooting 指南；Gradle 作为 Spring Boot 官方构建工具可用）。
  技术栈已由学习者确认；若将来换栈，整组替换已产出课程的桥接句，不要只改个别句子。
- 课文原文与桥接句都必须核对可信来源，不凭记忆书写；桥接句优先一手官方文档，逐字摘录并附链接。

## Out of scope

- 口语发音的地道性（发音顺带练，不作主线）。
- 第三册及以上内容。
- 针对具体考试的题型训练。
