# 教学笔记

## 学习者画像

- 起点：初中基础，偏薄。词性、句子成分需要从头讲。
- 终点：读懂英文技术资料（文档、报错、issue、论文）。
- **定位：本目录是纸质教材与视频课程的配套导学手册，不是练习场。**
  页面纯阅读：不做交互组件、不写 localStorage、不收集学习结果反馈。
  做题与讲解交给纸质教材和视频课程；需要对话式练习时用第 06 节的 AI 提示词。
- 节奏：每天一课，跟教材进度走，走完即止。
- 技术栈：Spring Boot / Spring Framework / OpenJDK（学习者已确认）。
  桥接语料以此生态的官方文档为准：报错栈、issue、release notes、troubleshooting 指南。
  Gradle 是 Spring Boot 官方支持的构建工具，Lesson 1 第 05 节的四句桥接句继续有效，无需替换。

## 课程结构：固定的六个环节

每课都走同一套结构。这是 2026-11-03 定稿的，**不要随课程变动**。
样板见 [lessons/0001-a-private-conversation.html](lessons/0001-a-private-conversation.html)。

| # | 环节 | 做什么 | 用什么样式 |
| --- | --- | --- | --- |
| 01 | 今天的技能 | 一句话给出技能名 + 为什么读技术资料需要它 + 一句真实技术句作 hook | `.skill` / `.bridge` |
| 02 | 最小装备 | 8 个左右核心词卡（每条含一个常见搭配、一个典型误用）+ 最多两张对照表，明确写「不要背」 | `.words` / `table` |
| 03 | 逐句示范 | 课文核心 3–4 句，每句书面走同样三步（找动词 → 定时态 → 搭骨架），读者跟着看「我是怎么想的」 | `.sentences` |
| 04 | 生活场景 | 3 个现实场景，每个 2–3 句，各配一条「别这么说」对照；场景在同事闲聊 / 电话或约人 / 日常安排之间轮换 | `.scene` |
| 05 | 桥接 | 4 句真实技术原文，逐字摘录，显式映射「骨架 = 第 03 节第 N 句」 | `.bridge` |
| 06 | AI 收尾 | 三个角色的复制提示词（陪练 / 批改员 / 考官）+ 一句话复习提醒 | `.prompt` / `prompt.js` |

被删掉的环节（2026-11-03）：点词拆句、回译草稿、选择题测验、60 秒默写。
练习不由本目录承担；想练时两个出口——纸质教材本身有习题，AI 考官提示词能出回译与仿写题。

## 分工：谁承担教学的哪一段

- **纸质教材 + 音频**：课文主体、生词表、课后习题。
- **视频课程**：语法讲解。
- **本目录**：课前导读（01 技能 + 02 装备），课后深化（03 示范 + 04 场景 + 05 桥接），AI 引流（06）。
- **AI 工具**：唯一的对话式练习出口，通过复制提示词接入。

判断一课读完有没有效果：能否说出本课唯一收获是哪一句，能否复述第 04 节里任意
一个场景的两句英文。说不出来就回 `reference/lesson-0N-text.html` 手册重读那一句。

## 教学偏好与约定

- 中文讲解为主，英文术语首次出现时给中文对照。
- 每课只给一个明确收获，宁浅勿深。
- **课文原文必须核对可信来源，不凭记忆书写**；每课页脚标注全部来源。
- **桥接句同样必须核对官方来源**，优先一手文档（release notes、user guide、changelog），
  不用二手博客；逐字摘录，不改写，并附来源链接与所在小节名。
- **每课必须讲清「现实中怎么用」**：第 04 节的场景取自上班族的真实对话，
  每个场景至少有一句是学习者第二天就可能说出口的，不能只停留在课文情节。
- 中英混排时，中文与英文/数字之间加一个半角空格。
- 每课必须能独立打开：纯静态、无构建、无外部依赖，`file://` 直接双击可用。

## AI 交互：只做提示词，不调接口

课程不调用任何 AI API。交互方式是「复制提示词 → 粘到任意 AI 对话」，
组件见 `assets/prompt.js`，提示词库见 [reference/ai-prompts.html](reference/ai-prompts.html)。
三个角色的按钮统一嵌在第 06 节，一节收口。

三个角色固定：

| 角色 | 做什么 |
| --- | --- |
| 陪练 | 扮演同事，用英文一问一答，把本课骨架用进真实对话 |
| 批改员 | 收学习者写的句子（教材习题、自发消息），按准确 / 时态 / 地道三条标准批改 |
| 考官 | 出三句中文让学习者回译，答完公布参考答案并打分；替代纸质默写 |

提示词本身用中文下指令，角色扮演部分要求 AI 说英文。
输出契约统一：**先总评、只改一处、再给升级版**——一次只改一个毛病，
避免 AI 一次列出十几条错误把学习者淹掉。
学习结果不回流到课程生成：下一课只依据教材进度与本页结构生成，不做学情反馈。

## lesson 与 reference 的分工

两者不重复。课程页是**导学**，reference 里的是**手册**。

- `lessons/`：六环节导学页，批注只讲与本课技能相关的点。
- `reference/lesson-0N-text.html`：完整批注版，含全部生词、搭配、文化注释，可打印，供课后查阅。
- `reference/*.html`（语法速查）：只讲语法规律，不绑具体课文。
- [reference/ai-prompts.html](reference/ai-prompts.html)：提示词库，三个角色各一份通用模板，每课再各写一份。
- `reference/review.html`：**唯一需要反复回来的文档**。每完成一课在第 01、02、04、05 节追加行，
  并在第 07 节记一行更新记录。不重写已有内容——这张表的价值在于越来越长。
  学习者只来回看，不在这里登记学习结果。

## 文件与命名约定

- 课程：`lessons/000N-<dash-case>.html`，编号递增，不复用。
- 课文批注：`reference/lesson-0N-text.html`。
- 总入口：`index.html`——课程与速查的唯一入口；课程按 1–24 / 25–48 / 49–72 / 73–96
  分四个单元，新增课程时只在对应单元追加一行，不改页面结构，未上线单元不显示。
- 共享样式：`assets/course.css`——所有页面统一引用，保证整套课看起来是一门课。
- 组件：只剩 `assets/prompt.js`（复制提示词）。
  `sentence.js` / `quiz.js` / `translate.js` 已于 2026-11-03 随交互环节删除，页面不得再引用。
- 词汇表：`reference/glossary.html`——待学习者能正确使用某个术语后再收录，不做成词典。
  **前两课均未触发，尚未创建。**
- `learning-records/` 不再作为课程流程的一部分；仅保留
  [0001-baseline-diagnostic.md](learning-records/0001-baseline-diagnostic.md) 作历史归档，
  该文件顶部已注明不再执行。

## 组件接口约定（写课程时必须遵守）

`prompt.js` 用 `data-copy-prompt="<template-id>"` 绑定按钮，从对应 `<template>` 读取提示词：
`<template>` 内用多个 `<p>` 分段，JS 按空行拼接；`<br>` 会转成换行。
按钮点击后短暂显示「已复制」；`file://` 下 Clipboard API 不可用时自动退回 `execCommand`；
两者都失败时把提示词展开成可选中的文本块并自动全选。

除此之外页面不放任何 JS 行为：不生成测验、不记录作答、不读写 localStorage。
