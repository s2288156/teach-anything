# 教学笔记

## 学习者画像

- 起点：初中基础，偏薄。词性、句子成分需要从头讲。
- 终点：读懂英文技术资料（文档、报错、issue、论文）。
- 节奏：每天一课。**不卡时长**，以「走完四步闭环」为完成标准（见下）。
- 技术栈：Spring Boot / Spring Framework / OpenJDK（学习者已确认）。
  桥接语料以此生态的官方文档为准：报错栈、issue、release notes、troubleshooting 指南。
  Gradle 是 Spring Boot 官方支持的构建工具，Lesson 1 第 08 节的四句桥接句继续有效，无需替换。

## 课程结构：固定的九个环节

每课都走同一套结构。这是 2026-10-23 定稿的，**不要随课程变动**。
样板见 [lessons/0001-a-private-conversation.html](lessons/0001-a-private-conversation.html)。

| # | 环节 | 做什么 | 用哪个组件 |
| --- | --- | --- | --- |
| 01 | 今天的技能 | 一句话给出技能名 + 为什么读技术资料需要它 + 一句真实技术句作 hook | `.skill` / `.bridge` |
| 02 | 最小装备 | 8 个左右核心词卡（每条含一个常见搭配、一个典型误用）+ 最多两张对照表，明确写「不要背」 | `.words` / `table` |
| 03 | 拆解示范 | 3 句，每句走同样的三步，逐步演示「我是怎么想的」 | `sentence.js` demo 模式 |
| 04 | 你来拆 | 5 句左右，点词找成分，点错标红并告知它其实是什么 | `sentence.js` find 模式 |
| 05 | 中译英回译 | 4 句，先写完再展开对照，草稿自动存本地 | `translate.js` / `prompt.js` |
| 06 | 混合检索 | 6 题，类型故意打乱（找错/词义/句型/理解/词性/搭配交错）；**无计时、不写记录** | `quiz.js`（不加 `data-quiz`） |
| 07 | 生活场景 | 3 个现实场景，每个 2–3 句，各配一条「别这么说」对照；场景在同事闲聊 / 电话或约人 / 日常安排之间轮换 | `.scene` / `prompt.js` |
| 08 | 桥接 | 4 句真实技术原文，逐字摘录，显式映射「骨架 = 第 03 节第 N 句」 | `.bridge` |
| 09 | 产出与收口 | 一个现实任务（如给同事写一条消息）+ 自检清单 + 60 秒默写 | `.task` / `.checklist` / `.recall` / `prompt.js` |

## 四步闭环：唯一的质量锚点

时长约束已取消，改用四步闭环防膨胀、防注水。**走完就结束**，不凑时长，也不砍环节。

1. **示范**（03）——我做给你看，重点是思考顺序而非答案。
2. **你练**（04 + 05）——点词拆解 + 回译重建。回译比选择题难，也比选择题有用。
3. **检索**（06）——交错检索，只要求「不要往回翻，凭记忆答」，不计时不记录。
4. **产出**（09）——写出来。这是把知识变成能力的唯一环节。

判断一课是否合格：四步各占到了吗？第 04、05、06 节能不能不回看第 02、03 节就完成？
若某一步只能靠翻上面才做得了，那是 fluency 错觉，不是掌握。

## 教学偏好与约定

- 中文讲解为主，英文术语首次出现时给中文对照。
- 每课只给一个明确收获，宁浅勿深。
- **课文原文必须核对可信来源，不凭记忆书写**；每课页脚标注全部来源。
- **桥接句同样必须核对官方来源**，优先一手文档（release notes、user guide、changelog），
  不用二手博客；逐字摘录，不改写，并附来源链接与所在小节名。
- **每课必须讲清「现实中怎么用」**：第 07 节的场景取自上班族的真实对话，
  每个场景至少有一句是学习者第二天就可能说出口的，不能只停留在课文情节。
- 测验即时反馈，选项严格等长（中文选项对齐字数），正确答案位置分散，避免连续同位。
- 中英混排时，中文与英文/数字之间加一个半角空格。
- 每课必须能独立打开：纯静态、无构建、无外部依赖，`file://` 直接双击可用。

## AI 交互：只做提示词，不调接口

课程不调用任何 AI API。交互方式是「复制提示词 → 粘到任意 AI 对话」，
组件见 `assets/prompt.js`，提示词库见 [reference/ai-prompts.html](reference/ai-prompts.html)。

三个角色固定：

| 角色 | 用在哪 | 做什么 |
| --- | --- | --- |
| 考官 | 第 09 节 | 出三句中文让学习者回译，答完再公布参考答案并打分 |
| 批改员 | 第 05 节 | 收学习者的四句译文，按准确 / 时态 / 地道三条标准批改 |
| 陪练 | 第 07 节 | 扮演同事，用英文一问一答，把本课骨架用进真实对话 |

提示词本身用中文下指令，角色扮演部分要求 AI 说英文。
输出契约统一：**先总评、只改一处、再给升级版**——一次只改一个毛病，
避免 AI 一次列出十几条错误把学习者淹掉。

## lesson 与 reference 的分工

两者不重复。课程里的课文是**练场**，reference 里的是**手册**。

- `lessons/`：交互式，课文句子作为拆解练习的语料，批注只讲与本课技能相关的点。
- `reference/lesson-0N-text.html`：完整批注版，含全部生词、搭配、文化注释，可打印，供课后查阅。
- `reference/*.html`（语法速查）：只讲语法规律，不绑具体课文。
- [reference/ai-prompts.html](reference/ai-prompts.html)：提示词库，三个角色各一份通用模板，每课再各写一份。
- `reference/review.html`：**唯一需要反复回来的文档**。每完成一课在第 01、02、04、05 节追加行，
  并在第 07 节记一行更新记录。不重写已有内容——这张表的价值在于越来越长。

## 组件接口约定（写课程时必须遵守）

`data-translate` 的值会拼进 localStorage 键（前缀 `nce-english:translate:`），
**必须全工作区唯一**，建议 `l<N>-tr-<M>`。

`data-quiz` 是可选增强，前缀 `nce-english:quiz:`。当前第 06 节**不加**这个属性，
因此测验无开始闸门、不计时、不写 localStorage、不出现记录条。
只有需要留档的测验才加，值建议 `l<N>-<节号>`。
加了之后才会计时，并在尾部出现记录条（上次记录 · 复制为 Markdown · 清空）。

**计时口径**（仅 `data-quiz` 测验）：题目前有「开始答题」按钮，未点之前选项是禁用的。
总用时从点击那一刻起算，到答完最后一题时停止；单题用时是相邻两次作答的间隔
（第一题含读题时间）。不把页面载入时间算进去，是为了避免滚动、误触、中途离开污染第一题的数据。

`sentence.js` 的讲解文字必须写在 `.sent-fb` 的 `data-text` 属性里，不能写在元素内容中
（JS 会用 `textContent` 覆盖它）。

`data-step` 从 1 开始，累积点亮（点过的不熄灭），符合「拆解逐层搭建」的认知顺序。

`prompt.js` 用 `data-copy-prompt="<template-id>"` 绑定按钮，从对应 `<template>` 读取提示词：
`<template>` 内用多个 `<p>` 分段，JS 按空行拼接。按钮点击后短暂显示「已复制」；
`file://` 下 Clipboard API 不可用时自动退回 `execCommand`。
