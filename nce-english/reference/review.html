Everything You Have Learned, On One Page

怎么用：每天开新课之前，先花两分钟看这一页。 不是读一遍，而是盖住右列，只看左列的中文，把英文骨架说出来。 说不出来的那一行，就是今天该补的地方。以后每学一课，都回到这一页自测。

01句子骨架

加粗的是必须变的词。「课文例句」帮你回忆来源，「技术例句」告诉你它真实长在哪。

骨架结构课文例句技术例句
过去时肯定 主语 + 动词过去式 I went to the theatre. The build failed.
过去时否定 主语 + did not + 动词原形 I did not enjoy it. The daemon did not start.
过去时疑问 Did + 主语 + 动词原形? Did you enjoy it? Did the test pass?
be 动词过去时 主语 + was / were + 形容词或名词 The play was very interesting. The property was null.
过去进行时 主语 + was / were + 动词 ing They were talking loudly. The task was still running.
情态动词过去式 主语 + could / would + 动词原形 I could not bear it. The client could not connect.
过去时被动 主语 + was / were + 过去分词 （Lesson 1 未出现，见技术文档原句） The callback was executed.
get + 形容词 主语 + got + 形容词（表变化） I got very angry. The queue got very long.
一般现在时（习惯） 主语 + 动词原形（三单加 -s） I never get up early on Sundays. The service starts in three seconds.
一般现在时疑问（do） Do / Does + 主语 + 动词原形? Do you always get up so late? Does the container create the bean?
现在进行时（此刻） 主语 + am / is / are + 动词 ing It’s raining again. The application is currently failing.
现在进行时疑问 Am / Is / Are + 主语 + 动词 ing? What are you doing? Is the service running?
现在进行时 + still 主语 + be + still + 动词 ing I’m still having breakfast. The task is still running.
频率副词位置 主语 + never / sometimes / always + 实义动词 I sometimes stay in bed until lunchtime. The daemon always starts after boot.
现在进行时被动 主语 + am / is / are + being + 过去分词 （Lesson 2 未出现，见技术文档原句） CommandLineRunner and ApplicationRunner components are being processed.
一般现在时被动 主语 + am / is / are + 过去分词 （Lesson 2 未出现，见技术文档原句） These states are exposed as health endpoint groups.
现在完成时肯定 主语 + have / has + 过去分词 I have just received a letter. We have added a new setting for the export timeout.
现在完成时否定 主语 + have / has + not + 过去分词 （Lesson 4 未出现，见课程页第 06 节） We have not finished the migration yet.
现在完成时疑问 Have / Has + 主语 + 过去分词? （Lesson 4 未出现，见课程页第 06 节） Have you tested it on Java 17?
完成时 + for + 时段 主语 + have / has + 过去分词 + for + 一段时间 He has been there for six months. We have used this configuration for two years.
双宾语（人先物后） 主语 + 动词 + 人 + 物 He lent me a book. This change gives the on-call team a clear error message.
双宾语换序（to） 主语 + 动词 + 物 + to + 人 I did not send cards to my friends. The job sends the report to the shared drive.
双宾语换序（for） 主语 + 动词 + 物 + for + 人 （Lesson 3 未出现，见课程页第 02 节） I bought a card for you.
tell + 人 + 内容 主语 + tell + 人 + that 从句 / to + 原形 （Lesson 3 未出现，见技术文档原句） It tells Spring that any HTTP request with the / path should be mapped to the home method.
截至现在（up to now / so far） Up to now / So far, 主语 + have / has + 过去分词 Up to now, Mr. Scott has sent a great many requests for spare parts. So far, no one has reported a problem.
旧情况（Previously） Previously, 主语 + 动词过去式 （Lesson 5 课文未出现，见课程页第 05 节技术文档原句） Previously, users could not download large files.

技术例句中，除以下四处外，均为按骨架构造的示意句： The callback was executed 摘自 Gradle 8.10 Release Notes； CommandLineRunner and ApplicationRunner components are being processed 与 These states are exposed as health endpoint groups 逐字摘自 Spring Boot Reference · SpringApplication 的 Readiness State / Application Availability 两节； It tells Spring that any HTTP request with the / path should be mapped to the home method. 逐字摘自 Spring Boot 官方教程 · The @RestController and @RequestMapping Annotations。

02聊天句与工作句（累积）

骨架会背还不够，得能开口说出来。每课收 3 条聊天句（课程页第 04 节）和 6 条工作句 （课程页第 06 节：3 句演示 + 3 句会议）；speaking/ 工作口语课的脚本句也登记在这里，来源标 S00N。 复习时和骨架表一起过——盖住英文，看中文说英文。工作句尤其要出声说，它们是你第二天就可能用上的。

来源中文英文注意
L1 · 聊天 周末过得怎么样？／挺好的，我和家人去了新餐厅。 How was your weekend? / It was great. I went to a new restaurant with my family. 已过完的周末用 was / went，不用 is / go。
L1 · 聊天 抱歉，我当时在开会，手机没带在身上。 Sorry, I was in a meeting. I didn’t have my phone with me. 「当时在」用 was；didn’t 后面是原形。
L1 · 聊天 我昨天开了三个会，所以没时间。 I had three meetings yesterday, so I didn’t have time. yesterday 锁死过去，两个动词都变过去式。
L1 · 演示 这个功能是上周上线的，修掉了大文件导出的超时。 We shipped this last week. It fixed the timeout on large exports. last week 前面不加介词；两句的动词都是过去式。
L1 · 演示 改之前，请求会失败，而且拿不到任何日志。 Before this change, the request failed and we did not get any logs. did not 后面必须是原形 get，不是 got。
L1 · 演示 测过了，昨天在 staging 上跑的，没问题。 Yes, we ran it on staging yesterday, and it was fine. run → ran 不规则；yesterday 锁死过去时。
L1 · 会议 不好意思，我没听清，能再说一遍吗？ Sorry, I did not catch that. Could you say it again? Could you 比 Can you 客气，会议上更安全。
L1 · 会议 所以我们定的是周二——我理解得对吗？ So we agreed on Tuesday — did I get that right? 结尾是 Did + 主语 + 原形；这句能把「没听懂」变成「在对齐」。
L1 · 会议 这个我不太确定，上次改完反而更糟了。 I was not sure about that one — last time it got worse after the change. got + 形容词 表示「变得」；把不同意挂在上次的结果上。
L2 · 聊天 我平时八点出门，但今天早上在等一个快递。 I usually leave home at eight, but I’m waiting for a delivery this morning. usually 配一般现在时；此刻用 am + -ing。
L2 · 聊天 你现在在做什么？／我在写报告。 What are you doing now? / I’m working on the report. 问此刻用 What are you doing，不用 What do you do。
L2 · 聊天 我平时去食堂，但今天在工位吃。 I usually go to the canteen, but today I’m eating at my desk. 一句里对照「平时」和「今天」，时态必须分开。
L2 · 演示 这个任务每天夜里两点跑，把报告写到共享盘。 This job runs every night at two, and it writes the report to the shared drive. 说常态用一般现在时，主语是三单，动词都要加 -s。
L2 · 演示 这一版会重试三次，网络慢的时候任务也不会失败。 This version retries three times, so the job does not fail on a slow network. does not + 原形；对应第 1 课的 did not，只是时间换成常态。
L2 · 演示 我们还在测。下周启动。 We are still testing it. We plan to launch next week. be + still + -ing 说此刻；后半句用一般现在时 plan（主语 we 接原形）说当前的计划状态。
L2 · 会议 抱歉，我没跟上，能再说一遍吗？ Sorry, I am not following you — could you say that again? 此刻用进行时；比 I don’t understand 缓和得多。
L2 · 会议 所以周五发布、今天开始冻结——我理解得对吗？ So we plan to ship on Friday and the freeze starts today — do I have that right? 前半句用一般现在时 plan（主语 we 接原形）；后半句是一般现在时三单 starts；结尾是 Do + 主语 + 原形。
L2 · 会议 我不太确定这样行，那个时间段队列一向很长。 I am not sure that works — the queue gets very long at that hour. 用一条常态事实（队列一向很长）承载不同意，不针对人。
S001 · 演示 这个任务负责导出月度报告，并把它写到共享盘。 This job exports the monthly report and writes it to the shared drive. 说功能常态用一般现在时，主语三单，两个动词都加 -s。
S001 · 演示 上个月队列变得很长，导出要跑四十分钟。 Last month the queue got very long, and the export took forty minutes. get + 形容词 说变化；last month 前面不加 in。
S001 · 演示 大文件的请求会失败，而且我们拿不到任何日志。 The request failed on large files, and we did not get any logs. did not 后面必须是原形 get。
S001 · 演示 用户关掉页面时，任务还在跑。 The task was still running when the user closed the page. 过去进行时和 when 后面的一般过去时在一句里错开。
S001 · 演示 所以我们改了导出链路，上周上线了。 So we changed the export path. We shipped it last week. ship 是工程口语的默认动词，比 release 更像人话。
S001 · 演示 现在报告三分钟就生成好了，而且总是落在同一个目录。 Now the report is generated in three minutes, and it always lands in the same folder. 系统行为用一般现在时被动；always 放在实义动词前面。
S001 · 演示 大文件那条路我们还在测，旧接口我们计划下周下掉。 We are still testing the large-file path, and we plan to remove the old endpoint next week. be + still + -ing 说此刻仍在进行；后半句用一般现在时 plan（主语 we 接原形）说当前的计划，to 后面跟 remove 原形。
S001 · 演示 我这边讲完了。关于灰度发布，大家有什么问题吗？ That is all from me. Do you have any questions about the rollout? 标准收尾，明确把话头交回去；Do + 主语 + 原形。
S001 · 别说 导出现在快多了，三分钟就跑完。 The export is much faster now. It takes three minutes. 不说 very perfect；「功能」是 feature，function 指代码里的函数。讲改进给数字，不给程度副词。
S001 · 别说 这个我们昨天上线了。 We shipped this yesterday. yesterday 已锁死时间，不加 already；finish 是做完了，ship 才是上线了。
S001 · 别说 我这样讲清楚了吗？ Does that make sense? 不说 Do you understand——听着像质疑对方理解力。责任放在「我有没有说清楚」上。
L3 · 聊天 你有充电器能借我吗？／有，我借你我的。 Do you have a charger I can borrow? / Sure, I can lend you mine. borrow 是借入、只跟物；lend 是借出，先跟人再跟物。
L3 · 聊天 抱歉没接到你电话。／没事，我把幻灯片发给全组了。 Sorry, I missed your call. / I sent the deck to the whole team. 物在前时用 to 把人接回来；人紧跟动词则不写 to。
L3 · 聊天 我去拿咖啡，帮你带一杯？／好啊，明天午饭我请。 I’m getting coffee. Can I get you one? / Lunch is on me tomorrow. 替人带东西是 get you one；on me 是「我请客」。
L3 · 演示 这个改动让值班同事看到的是一条清楚的报错，而不是一长串栈信息。 This change gives the on-call team a clear error message instead of a stack trace. 讲「谁受益」就把人放在动词后第一位：give + 人 + 物。
L3 · 演示 任务每天夜里把报告写到共享盘，另外给我发一份简短摘要。 Every night the job sends the report to the shared drive, and it sends me a short summary. 同一个 send，前半物先人后，后半人先物后，两种排法都对。
L3 · 演示 文档我今早发给全组了。你要详细版吗？ I sent the link to the whole team this morning. Do you want the longer version? 过去的事用过去式；第二句是 Do + 主语 + 原形。
L3 · 会议 抱歉我没听清，能再给我一遍那个数字吗？ Sorry, I missed that — could you give me the number again? 比 say that again 具体：give me + 物。
L3 · 会议 所以你是说迁移周一开始——我理解得对吗？ So you are telling me the migration starts on Monday — do I have that right? tell 后面先人后内容；结尾用 Do 疑问收口。
L3 · 会议 我不太确定这样能行——上次那个改动带来的问题比解决的多。 I am not sure that works — the last change gave us more problems than it solved. 用过去式 gave us 把不同意挂在上一次的结果上。
L4 · 聊天 你去过新开的那家咖啡店了吗？／还没，我刚出差回来。 Have you been to the new coffee place yet? / Not yet. I have just got back from a trip. yet 放句尾用于疑问和否定；have been to 是去过（经历）。
L4 · 聊天 构建跑完了吗？／跑完了，测试也全都过了。 Has the build finished? / Yes, it has. It has already passed all the tests. 简短回答只重复助动词；already 夹在 has 和过去分词之间。
L4 · 聊天 我刚搬到公司附近。／你找到合适的咖啡店了吗？ I have just moved to a flat near the office. / Have you found a good coffee place yet? 「刚搬来、现在住这儿」用完成时；有 last week 就要改过去式。
L4 · 演示 我们为导出超时新增了一个配置项。 We have added a new setting for the export timeout. 讲新功能先给结果：have added 说「现在有了」。
L4 · 演示 我们用新配置替换了旧开关，旧名字已经从文档里消失。 We have replaced the old flag with a new setting, and the old name has already disappeared from the docs. 两个分句都用现在完成时；replace A with B = 用 B 替换 A。
L4 · 演示 你们在 Java 17 上测过吗？／测过了，已经在 Java 17 上跑过。 Have you tested it on Java 17? / Yes, we have already run it on Java 17. Have + 主语 + 过去分词 提问；run 的过去分词与过去式同形。
L4 · 会议 抱歉我没听清，能再给我一遍那个数字吗？ Sorry, I have not caught that — could you give me the number again? 前半是完成时否定；后半 give me + 物是第 3 课的双宾语。
L4 · 会议 所以迁移已经开始了——我理解得对吗？ So the migration has already started — do I have that right? has already started 说现在已经在跑；结尾用 Do 疑问收口。
L4 · 会议 我不太确定这样有效——上次那个改动带来的问题比解决的多。 I am not sure that has worked — the last change gave us more problems than it solved. 前半 has worked 说到现在没见效；后半 gave us 回到过去式。
L5 · 聊天 周末干什么好玩的了吗？／我昨天骑了新车。到目前我已经骑了三十公里。 Did you do anything fun over the weekend? / I rode my new bike yesterday. So far, I have covered thirty kilometres. 问「周末那一次」用 Did ... do；So far 说到眼下，必须配 have covered。
L5 · 聊天 我昨天发的消息你收到了吗？／收到了，我刚给你回了信。 Did you get my message yesterday? / Yes, I got it, and I have just sent you a reply. yesterday 钉死过去式；「回复已经发出、现在在你那儿」用 have just sent。
L5 · 聊天 修理工来了吗？／还没。他十分钟前打过电话，说午饭之后过来。 Has the repairman come yet? / Not yet. He called ten minutes ago; he will come after lunch. 问「截至现在」用 Has ... yet；ago 钉死过去式 called。will come 认得即可。
L5 · 演示 我们昨天移除了旧开关。到目前为止，没有人报过问题。 We removed the old flag yesterday. Up to now, no one has reported a problem. 两句话把改动时间线说完整：yesterday + 过去式，Up to now + 现在完成时。
L5 · 演示 以前用户下载不了大文件。这个版本我们把它修好了。 Previously, users could not download large files. We have fixed that in this release. Previously 带出旧情况（过去式），第二句用现在完成时给出现在的结果。
L5 · 演示 今早构建过了吗？／过了，而且我们已经开始了灰度发布。 Did the build pass this morning? / Yes, and we have already started the rollout. 问「今早那一次」用 Did + 主语 + 原形；答「已经开始」用完成时 + already。
L5 · 会议 抱歉，电话刚才断了——能把最后那部分再说一遍吗？ Sorry, the line broke up — could you repeat the last part? broke up 是刚才发生的那一次；could you 比 can you 客气。
L5 · 会议 所以试点昨天结束、灰度下周开始——我理解得对吗？ So the pilot ended yesterday and the rollout starts next week — do I have that right? yesterday 配过去式 ended；日程安排用一般现在时三单 starts。
L5 · 会议 我不确定现在就要改——到目前为止，旧脚本从来没出过问题。 I am not sure we need to change it now — up to now, the old script has never failed. up to now + has never failed，拿「截至现在的事实」委婉顶回「现在要改」。

03三步拆句法（贯穿全部 96 课）

找动词 → 定时间 → 切主干。

拿到任何陌生英文句子，都走这三步。 第一步找动词（注意动词可能是两三个词合起来的：were sitting、did not enjoy、was executed）； 第二步看动词的形态判断时间（过去式 = 已结束，原形/三单 = 常态，ing = 正在进行， have / has + 过去分词 = 过去发生、现在有结果）； 时间词也直接给答案：yesterday、last night、ago 钉死过去式， up to now、so far 钉死现在完成时（Lesson 5 新增）； 第三步切出「谁 + 做了什么 + 对象/地点」。主干到手，剩下的修饰成分读不懂也不影响理解。

这个顺序不会变。变的是句子里出现的骨架越来越多。

Up to now, he sent a great many messages.Up to now, he has sent a great many messages.「截至现在」包括眼下这一刻，要用现在完成时
He has called ten minutes ago.He called ten minutes ago.ago 钉死过去，不能配 have / has
a great many of requestsa great many requestsa great many 直接跟复数名词，中间不加 of；想用 of 就换 a great number of
he has began his own servicehe has begun his own servicehave / has 后面用过去分词 begun，不是过去式 began

06复习节奏

这一页要按间隔回来看，而不是每天从头读一遍。间隔越长，记得越牢—— 刚学完就复习几乎没有效果，快要忘了的时候复习效果最好（这叫 desirable difficulty，合意困难）。

什么时候回来做什么预期
学完后第 2 天盖住英文，说出第 01 节的骨架（被动语态的行只要求认得）、第 02 节的聊天句与工作句，以及 S001 的演示句骨架说出四分之三以上、句子说出三分之二以上算过关
学完后第 4 天只说第 05 节的易错点，并各造一句错处不再犯
学完后第 8 天随机找一段英文技术文档，用三步法拆两句不需要提示就能走完三步
学完后第 16 天不回看，默写第 01 节的结构列，并把第 02 节的中文换成英文这一课就算真的进长期记忆了

做不到也没关系——做不到只说明间隔还不够长，把下一次复习往后推，而不是往前赶。
