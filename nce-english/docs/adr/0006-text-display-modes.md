# 全文批注版用纯 CSS 切换课文显示模式

全文批注版原来靠学习者自己「盖住中文」或「盖住英文」来练口译与理解。页面很长，手工遮挡不方便，
也不稳定。我们决定在页头加一个「课文显示」控件，三档：**中文 / 英文 / 双语**。

实现只用 CSS：三个同名单选按钮（`name="text-mode"`，`value` 为 `zh` / `en` / `both`）加 `:has()`，
按选中项隐藏对应内容；第 01 节英文句子外包 `<span class="en-text">`，中文译文沿用 `.cn`。
不写 JS、不读写 localStorage、不做 URL 状态；默认「双语」，刷新回到默认。
打印时强制中英双语，并隐藏控件。

切换只作用于**课文与译文**：第 01 节的英文和所有 `.cn`。第 02 节的 `.why` 讲解、生词表、
文化注释始终显示——这份页面的价值在批注，藏掉讲解会让它只剩一份普通课文。

## Considered Options

- **JS 切换并记住选择**：否。要引入 localStorage 与第二份脚本，破坏「零 JS、零状态」的底线；
  读者每次打开都从双语开始，代价很小。
- **为中文 / 英文 / 双语各生成一份页面**：否。三份内容会失同步，链接与打印也变复杂。
- **只做打印样式，屏幕仍靠手工遮挡**：否。屏幕上的练法正是这次要解决的痛点。

## Consequences

「页面不放交互组件」收窄为「不做练习、不记录作答、不嵌音频」；纯 CSS 的显示切换是阅读辅助，
不是练习，见 [ADR 0002](0002-pages-stay-read-only.md)。以后新增全文批注版必须复制
`.mode-switch` 与 `.en-text` 结构。实现依赖浏览器支持 `:has()`——2023 年起主流浏览器均已支持。
