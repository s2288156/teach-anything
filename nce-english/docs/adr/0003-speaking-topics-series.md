# 教材线之外新增 speaking 专题课系列

96 课跟完教材要好几个月，而工作沟通需求是当下的，二册里也没有任何演示 / 会议语料。
我们决定在 `lessons/` 之外开一条专题课系列：`speaking/S00N-<dash-case>.html`，编号独立、
按工作需求随时插入，主题如「演示脚本」「会议用语」「报错口头解释」。

**硬规则：专题课只允许使用 `reference/review.html` 已登记的骨架。**
这条限制让专题课同时充当间隔复习，也保证它不会跑到学习者能力之外。

## Considered Options

- **严格跟教材，只在六环节内部塞口语**：否。满足不了即时的演示 / 会议需求。
- **完全脱离教材，按工作场景组织全部课程**：否。见 [ADR 0001](0001-speaking-as-second-output.md)。
