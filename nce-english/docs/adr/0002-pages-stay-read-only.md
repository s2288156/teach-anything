# 课程页保持纯阅读：发音与个性化都外包

口语目标进来后，页面依然**不嵌 `<audio>`、不做语音识别评分、不收集任何学习结果反馈**。
标准发音由第三方 app 获取（学习者已有渠道）；个性化记忆放在 **AI 项目侧**——
豆包 / Trae / codex 均可建项目，把已学骨架库与输出契约写进系统指令，由 AI 承载长期记忆。

页面因此维持零 JS 行为（唯一例外是 `assets/prompt.js` 的复制按钮）、零 localStorage，
`file://` 双击可用这条硬约束不变。

## Considered Options

- **半破：页内嵌音频播标准发音**：否。第三方 app 已能满足，内嵌音频会带来资源体积与来源核对负担。
- **全破：页内语音识别 + 跟读评分**：否。浏览器兼容与隐私是无底洞，AI 语音模式做得更好。
- **手工「口语错误本」文档**：否。学习者明确要求依然不收集，错误复盘交给 AI 项目侧记忆。
