# 口语是同骨架的第二出口，不另立主线

> 术语已更新：标题中的「第二出口」现称「工作口语课」，
> 见 [ADR 0003](0003-speaking-topics-series.md) 与 [ADR 0005](0005-plain-chinese-section-names.md)。

2026-11-03 学习者补充目标：工作需要经常与外国人交流，并要用英文把自己开发的功能讲成课程与演示。
我们决定**保持技术文档阅读为主线**，二册继续提供语法骨架；同一骨架在每课同时给
「读得懂的技术句」与「说得出口的场景句」。口语场景锁定两类：**公司内部英文演示**（可脚本化）
与**跨国会议技术讨论**（即兴问答、澄清、表达不同意）。

理由：起点是初中基础，产出型技能缺少输入底座会卡在「想不出句子」而不是「说不准」；
二册 1–48 课的时态与语态正好是口语最缺的地基。

## Considered Options

- **双线并行**（另开一条不绑课文的口语线）：否。过早分裂精力；等骨架库到 25 课左右再评估。
  专题课形态另见 [ADR 0003](0003-speaking-topics-series.md)。
- **口语变主线**（脱离教材，按工作场景倒推语法词汇）：否。基础未稳就直面即兴口语。
