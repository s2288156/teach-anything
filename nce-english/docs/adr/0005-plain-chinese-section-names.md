# 章节名与术语改用日常中文

学习者指出「装备」「桥接」「技能」是生造的压缩术语，打开页面看不出那节要干什么。
我们决定七节全部改成日常说法：**01 这一课学什么 / 02 生词和搭配 / 03 一句一句拆开看 /
04 平时聊天怎么说 / 05 技术文档里怎么写 / 06 开会和演示怎么说 / 07 拿去和 AI 练**。

术语同步改名：桥接句 → 技术文档原句，导学 / 手册 → 课程页 / 全文批注版，
专题课 → 工作口语课，提示词三件套 → 三个 AI 角色（陪练 / 批改 / 出题）；
**取消**「口语第二出口」「最小装备」「生活场景」三个黑话，含义并入节名。
`assets/course.css` 的 class 一并改名（`.skill` → `.topic`、`.bridge` → `.docs`、
`.scene` → `.chat`，新增 `.speaking`），避免名实不符。

权衡：名字变长、失去标签式的简洁；换来的是每节标题自带动作提示。往后写课文案同样遵守
——**用日常中文，不生造压缩术语，必要时直接用英文**。

## Consequences

「句子骨架」保留：它含「主干 + 时态」的意思，换成「句型」会丢掉时态，且
`reference/review.html` 已按这个词建了 16 行表。代价是每页首次出现必须给一句白话解释。
